## Independent business-news collector — News Central Site

- Added a bounded, ticker-independent News Central Site public API adapter and a manual one-shot Supabase writer. Published API documentation describes unauthenticated summary access, a 60-request/minute limit, page/total/next-link metadata, permanent IDs, published/updated timestamps, and required publisher/canonical-link attribution. The source terms identify CC BY 4.0 coverage for stories and explicitly allow free use with attribution; the collector stores summaries and metadata only, not full text or images.
- The adapter caps a run at three pages and verifies each page's ordered permanent IDs twice. Invalid links/query scope, inconsistent counts, duplicate IDs, page drift, or exceeding the bound prevent checkpoint advancement. Returned records and append-only revisions are persisted transactionally in the existing evidence tables; raw news never enters the notification outbox. A stable bounded window may checkpoint, but complete news coverage remains explicitly false.
